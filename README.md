# mycoo_crm_client
Цифровой операционный директор

## Локальный запуск

Скопируйте `.env.example` в `.env.local`. `API_PROXY_TARGET` — адрес локального NestJS API, по умолчанию `http://127.0.0.1:3001`.

```sh
npm install
npm run dev
```

Проверки и сборка:

```sh
npm run typecheck
npm run build
```

Авторизация: email → проверка кода → пароль. При `NODE_ENV=development` на сервере код равен `111111`. Онбординг сохраняется в API после каждого из трёх шагов; при повторном входе продолжается с сохранённого этапа. Вопросы диагностики и итоговый профиль приходят с сервера. После ошибки анализа ответы можно повторно отправить.

`VITE_API_URL` задаёт публичный адрес API. В production для значения `/api` нужен reverse proxy с сохранением префикса `/api`; Vite-прокси работает только при разработке. Альтернатива — абсолютный URL API с разрешённым CORS. Хостинг должен отдавать `index.html` для клиентских маршрутов `/dashboard/*` и `/invite/*`.

Без `VITE_API_URL` сохраняется прежнее поведение: запросы идут на текущий origin без дополнительного префикса. Исходные параметры Vite (`0.0.0.0`, порт и HMR 3000) сохранены. Для локального порта 4190 задайте `DEV_HMR_PORT=4190` в `.env.local` и запустите `npm run dev -- --host 127.0.0.1 --port 4190`.

Ключ GigaChat и SMTP настраиваются только в backend. Остальные демонстрационные модули CRM не подключаются этим изменением.

## Команда и приглашения

Раздел команды находится на /dashboard/team. Департаменты, участники и роли загружаются из API; после изменения данные сохраняются на сервере. Роль выбирается отдельно для каждого департамента. Новая общая форма PasswordFields используется обычной регистрацией и страницей приглашения.

После диагностики предлагается создать первый департамент или пропустить этот шаг. При создании приглашения можно скопировать ссылку и текст для самостоятельной отправки. Ссылка формируется на текущем домене фронтенда; почтовая отправка пока не подключена. Маршрут /invite/:token проверяет ссылку через API, принимает пароль и открывает компанию без повторного онбординга. Для существующего аккаунта требуется его действующий пароль.

Для приглашённых участников вместо будущих задач и показателей департамента отображается заглушка. Функциональность канбана и нового дашборда в этот этап не входит.
